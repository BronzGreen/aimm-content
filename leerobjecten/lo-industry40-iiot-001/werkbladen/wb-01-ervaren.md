> **Wat je gaat doen:** je vergelijkt twee tijdlijnen van dezelfde pompstoring in twee productieomgevingen. De ene draait op single-message-AI (losstaande waarschuwingen). De andere draait op een continu data-driven platform. Beide zien dezelfde data binnenkomen — maar wat ze ermee doen is fundamenteel anders.

---

## Casus A — Single-message-AI

*Voedingsmiddelenfabriek, 2022. Centrifugaalpomp in een melkverwerking.*

| Tijdstip | Gebeurtenis |
|----------|-------------|
| 06:12 | AI-systeem stuurt e-mail: *"Trillingsniveau pomp P-04 in zone amber. Geadviseerde actie: inspectie binnen 48 uur."* |
| 09:30 | Onderhoudsmonteur leest e-mail in werkorderlijst. Gepland in week-31. |
| 14:45 | Tweede mail: *"Trillingsniveau zone red. Onmiddellijke actie."* |
| 14:52 | Productieleider belt onderhoud. Pomp draait nog door — geen autostop. |
| 15:08 | Pomplager faalt. Productiestop. Schade aan as. |
| 17:30 | Onderhoud arriveert. Reparatie tot 23:00. |
| | **Verlies:** 8 uur productie, €38.000 + reparatie. |

---

## Casus B — Continu data-driven platform

*Identieke pomp, identieke fabriek, 2024 (na platform-upgrade).*

| Tijdstip | Gebeurtenis |
|----------|-------------|
| 06:12 | Platform detecteert trillingsstijging. Vergelijkt met historische uitvalspatronen. Predictive-onderhoudsmodule berekent **resterende levensduur: 3-5 dagen**. |
| 06:13 | Werkorder automatisch aangemaakt en geplaatst in onderhoudsplanning. Onderdelen besteld via gekoppeld inkoopsysteem. |
| 06:15 | Productieleider ziet melding op operations-dashboard met **aanbevolen interventiemoment**: dinsdag tussen 02:00-04:00 (geplande omstel-stop). |
| Dinsdag 02:30 | Onderhoud vervangt lager tijdens geplande stilstand. Geen extra productieverlies. |
| Dinsdag 04:00 | Pomp draait weer. Platform monitort herstart-trillingscurve. |
| | **Verlies:** 0 uur ongepland, €1.200 onderdelen + 1,5 uur arbeid. |
