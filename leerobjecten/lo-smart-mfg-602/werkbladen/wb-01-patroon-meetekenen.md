# Werkblad 1 — Het patroon meetekenen

## Waarom doen we dit?

De trainer tekent zo het patroon op de flipover. Teken mee op dit blad. Schrijven terwijl je luistert helpt om het te onthouden.

---

## De vier zichtbare stappen

Teken in de lege vakken wat er gebeurt bij elke stap. Één woord of een simpele tekening is genoeg.

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│             │     │             │     │             │     │             │
│   CAMERA    │ --> │    BEELD    │ --> │    MODEL    │ --> │  BESLISSING │
│             │     │             │     │             │     │             │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘

Wat doet het?    Wat doet het?      Wat doet het?      Wat doet het?

_______________  ________________   ________________   ________________

_______________  ________________   ________________   ________________
```
