# Van pilot naar productie: AI-inspectie implementeren — voor de trainer

**Leerobject:** lo-smart-mfg-524
**Kennisobject:** ko-smart-mfg-524
**Doelgroep:** MBO-3 operator (Module 3 sluitstuk), B1 taalniveau
**Duur:** 37 min
**Bloom:** analyseren

## In één oogopslag

| | |
|---|---|
| Werkvormen | Storingsquiz fases, individuele reflectie + duo, korte handout drie-fasenmodel, pilotplan eigen lijn |
| Kolb-startfase | Ervaren — bewust bekwame doener herkent fases via quiz |
| Begeleidingsstijl | Trainen — drie fases (pilot, uitrol, standaard) als anker met aluminium-casus |
| Materialen | Vier werkbladen, SVG-diagram drie-fasen, simulator, flap-over (drie-fasen-as + pilotplannen) |

## Wat de deelnemer leert

De deelnemer kan de drie implementatiefases van AI-inspectie benoemen en analyseren welke fase past bij de eigen werkplek. Bij het implementatiemodel (pilot, uitrol, standaard) en de eigen productiesituatie wijst hij minimaal 3 kenmerken per fase correct toe en stelt een onderbouwd pilotplan op.

## Sessie-opbouw

| Fase | Tijd | Activiteit | Werkvorm |
|---|---|---|---|
| Ervaren | 0:00-0:08 | Storingsquiz: kenmerken aan fases toewijzen | Kleine groepen |
| Reflecteren | 0:08-0:18 | In welke fase zit mijn bedrijf? | Individueel + duo |
| Theoretiseren | 0:18-0:25 | Drie-fasenmodel + aluminium-casus | Korte uitleg + handout |
| Experimenteren | 0:25-0:37 | Pilotplan voor jouw lijn — wat, waar, wanneer, met wie? | Individueel + plenair |

## Tips voor de trainer

- **Bij "wij zijn daar nog niet klaar voor": bevestig.** "Klopt — dan zit je vóór fase 1." Maak duidelijk: dit model laat zien hoe het kan, niet hoe het móét. Een pilot kan klein beginnen — één lijn, één defecttype, drie maanden.
- **Pilotplan altijd concreet.** Bij "praten met manager" doorvragen: welke lijn, welk defecttype, hoeveel weken, wie is de inspecteur die parallel werkt. Een plan zonder lijn-defect-datum is geen plan.
- **Aluminium-casus als rode draad.** Lijn 3 (drukst, hoogste afkeur), 3 maanden pilot, AI 92% recall vs inspecteur 85%. Concrete cijfers ankeren de drie fases.
- **Geen verandermanagement-theorie.** Geen Kotter, ADKAR of change resistance. Drie fases met drie kenmerken is genoeg op MBO-3-niveau.
- **Maak van 'ik' altijd 'wij'.** Bij "ik regel het wel": "Een pilot vraagt om een team — operator + kwaliteit + IT + manager. Wie zijn jouw 3 mensen?"

## Valkuilen

- **Operator overschat eigen invloed.** "Ik regel het wel" is zelden waar. Dwing teamopstelling.
- **Pilotplan blijft op niveau van 'overleg met manager'.** Eis lijn, defecttype, weken, namen.
- **Geen tijd voor afsluiting.** Bewaar minstens 1 minuut voor transferopdracht — cap fase 4 op 11 min indien nodig.

## Voorbereiding (30 min vooraf)

- [ ] Vier werkbladen printen, n + 2 reserve
- [ ] SVG-diagram drie-fasen + simulator klaar op beamer
- [ ] Flap-over (twee vellen): drie-fasen-as + pilotplannen
- [ ] Whiteboard + stiften
- [ ] Tafels in clusters van 2-3, beamer + HDMI getest

## Transferopdracht

Geef de deelnemer mee om binnen twee weken zijn pilotplan aan de teamleider voor te leggen: één lijn, één defecttype, 4-12 weken duur, drie tot vier teamleden (operator, kwaliteit, IT, manager) en twee meetbare succescriteria. Bij goedkeuring start de pilot. Module-evaluatie volgt na de pilot.
