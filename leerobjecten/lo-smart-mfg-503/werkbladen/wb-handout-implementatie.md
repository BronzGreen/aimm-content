# Handout: Drie-fasen implementatiemodel

**Module 3: Op Maat | Predictive Maintenance**

---

## Van pilot naar standaard in drie fases

```
Fase 1: PILOT              Fase 2: UITROL             Fase 3: STANDAARD
1 machine, 3-6 maanden     Hele lijn, 6-12 maanden    Hele fabriek, 12+ maanden

    Bewijzen dat het        Opschalen naar de          Predictive maintenance
    werkt op JOUW           andere machines in         is de standaard
    werkvloer               de productielijn           werkwijze
```

---

## Fase 1: Pilot — jouw eerste machine

| Wat | Toelichting |
|-----|------------|
| **Machine** | De machine uit je business case |
| **Sensoren** | Installeren of activeren |
| **Data** | Minimaal 3 maanden verzamelen |
| **Drempels** | Instellen (Module 2) |
| **Registratie** | Elke voorspelde en gemiste storing noteren |
| **Duur** | 3-6 maanden |

**Wie betrek je:** jijzelf (operator), technische dienst, teamleider, leverancier (optioneel)

---

## Fase 2: Uitrol — de rest van de lijn

| Wat | Toelichting |
|-----|------------|
| **Machines** | Alle kritieke machines in de lijn |
| **Collega's** | Train collega-operators (dezelfde modules) |
| **Standaard** | Dashboard en werkprocedure standaardiseren |
| **Integratie** | PM opnemen in regulier onderhoudsplan |
| **Duur** | 6-12 maanden |

---

## Fase 3: Standaard — de hele fabriek

| Wat | Toelichting |
|-----|------------|
| **Alle machines** | Elke machine heeft basislijn + drempels + actieplan |
| **Data-gedreven** | Onderhoud op basis van data, niet kalender |
| **Samenwerking** | Operators en technische dienst delen het dashboard |
| **Nieuwe machines** | Direct ingericht met sensoren |

---

## De drie grootste valkuilen

| Valkuil | Hoe te vermijden |
|---------|-----------------|
| **1. Te groot beginnen** | Start met 1 machine. Bewijs het. Schaal dan op. |
| **2. Geen eigenaar** | Iemand moet verantwoordelijk zijn voor het dashboard. |
| **3. Alleen techniek** | Betrek operators, TD en management vanaf dag 1. |

---

## Succes meten

| Fase | Indicator | Doel |
|------|----------|------|
| Pilot | Storingen correct voorspeld | > 50% |
| Pilot | Reductie ongeplande stilstand | > 30% |
| Uitrol | OEE-verbetering | > 5% |
| Standaard | Onderhoudskosten | < 80% van huidige kosten |
