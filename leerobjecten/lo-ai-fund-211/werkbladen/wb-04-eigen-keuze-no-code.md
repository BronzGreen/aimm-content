## Stap 2: Beantwoord vier korte vragen

### Vraag a — Welk type data?

*Vink één keuze aan.*

- [ ] Beeld — foto's of camera-beelden.
- [ ] Geluid — audio-opnames.
- [ ] Tabel-data — getallen in rijen en kolommen.
- [ ] Een combinatie.

### Vraag b — Hoeveel voorbeelden heb je?

*Schat in. Een ruwe schatting is genoeg.*

- [ ] Minder dan 1000 voorbeelden.
- [ ] Tussen 1000 en 100.000 voorbeelden.
- [ ] Meer dan 100.000 voorbeelden.
- [ ] Ik weet het niet — ik moet dit eerst uitvragen.

### Vraag c — Moet het model real-time op de lijn werken?

- [ ] Nee — een prototype op een laptop is genoeg.
- [ ] Ja — het moet direct op de productielijn werken.
- [ ] Ik twijfel.

### Vraag d — Zit er gevoelige info in de data?

- [ ] Nee — alleen producten of materialen. Geen personen, geen geheimen.
- [ ] Ja — er staan werknemers op de foto, of er zit bedrijfsgeheim in.
- [ ] Ik weet het niet — ik moet dit nakijken.
