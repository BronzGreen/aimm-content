# Handout: Van probleem naar data-plan

**Leerobject:** Jouw kwaliteitsprobleem en jouw trainingsdata
**Kolb-fase:** Theoretiseren
**Type:** Theorie-handout
**Tijd:** 10 minuten

---

## De 5 stappen van probleem naar werkend AI-model

### Stap 1: Probleem kiezen
Bekijk je afkeurdata. Kies het defect dat het **meeste kost**. En dat **goed zichtbaar** is op een foto.

### Stap 2: Camera-opstelling bouwen

| Onderdeel | Checklist |
|---|---|
| Camera | [ ] Vast punt (statief of bevestiging) |
| | [ ] Vaste afstand tot product |
| | [ ] Vaste hoek |
| Achtergrond | [ ] Effen kleur (wit of grijs) |
| | [ ] Geen rommel in beeld |
| Verlichting | [ ] Minimaal 2 lichtbronnen |
| | [ ] Geen directe schaduw op product |
| | [ ] Geen daglicht (sluit ramen af) |
| Positie | [ ] Markering op tafel/band |
| | [ ] Elk product op dezelfde plek |

### Stap 3: Labelcriteria afspreken

Bespreek met minimaal 2 collega's:

| Vraag | Afspraak |
|---|---|
| Wanneer is een product "goed"? | _________________________________ |
| Wanneer is een product "defect"? | _________________________________ |
| Welke defecttypes onderscheiden jullie? | _________________________________ |
| Wat zijn de grenzen? (bijv. kras >2mm = defect) | _________________________________ |

**Regel:** als 2 van de 3 collega's het eens zijn over een label, is dat het label.

### Stap 4: Foto's maken en labelen

| Richtlijn | Minimum | Ideaal |
|---|---|---|
| Totaal aantal foto's | 100 | 200-300 |
| Percentage defect | 30% | 40-50% |
| Foto's per defecttype | 30 | 50-100 |

**Doe het samen:** verdeel het werk. De een maakt foto's, de ander labelt. Controleer steekproefsgewijs elkaars labels.

### Stap 5: Trainingsset en testset verdelen

- **80% trainingsset**: het model leert hiervan
- **20% testset**: hiermee test je het model

Zorg dat beide sets een goede mix hebben van goede en defecte producten.
