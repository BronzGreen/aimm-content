# Datakwaliteit beoordelen — drie checks die je zelf kunt doen — voor de trainer

**Leerobject:** lo-data-lit-202
**Kennisobject:** ko-data-lit-202
**Doelgroep:** MBO-3 operator (primair), MBO-4 (secundair), B2 taalniveau (trainer)
**Duur:** 30 min (workshop-blok module 2 Train)
**Bloom:** toepassen

## In één oogopslag

| | |
|---|---|
| Werkvormen | Individuele check op voorbeelddataset, duo-reflectie, korte uitleg met handout, individueel actieplan |
| Kolb-startfase | Ervaren — direct zelf doen op een dataset uit een spuitgieterij |
| Begeleidingsstijl | Coachen — weinig taaksturing, veel procesondersteuning |
| Materialen | Vier werkbladen (ervaren / reflecteren / theorie+stoplicht / actieplan), voorbeelddataset spuitgieten 25 rijen, flap-over met drie kolommen V/C/A, markeerstiften groen/oranje/rood per duo |

## Wat de deelnemer leert

De deelnemer voert de drie datakwaliteitschecks (volledigheid, consistentie, actualiteit) zelfstandig uit op een productiedataset en geeft een onderbouwd stoplicht-oordeel (groen/oranje/rood). Hij kiest aan het eind een dataset op de eigen werkvloer waar hij de checks gaat toepassen — geen oefencontext meer.

## Sessie-opbouw

| Fase | Tijd | Activiteit | Werkvorm |
|---|---|---|---|
| Ervaren | 0:00-0:10 | Drie checks zelfstandig op voorbeelddataset (spuitgieten, 25 rijen) | Individueel |
| Reflecteren | 0:10-0:18 | Duo-reflectie — wat zag je, wat was lastig? | Duo |
| Theoretiseren | 0:18-0:25 | Drie checks expliciet maken — vuistregels + stoplicht | Trainer + handout |
| Experimenteren | 0:25-0:30 | Actieplan eigen werkvloer | Individueel |

## Tips voor de trainer

- **Loop rond, ga NIET bij iemand zitten.** Korte coach-momenten van 30 seconden per deelnemer is genoeg.
- **Geef GEEN antwoord op *"klopt dit?"*** Vraag terug: *"Wat denk JIJ?"* Coachen, niet trainen.
- **Bij vastlopen na 3 minuten: geef ÉÉN check tegelijk.** *"Doe nu eerst alleen volledigheid."* Stuk-voor-stuk verlaagt de cognitieve belasting.
- **Bewaak het eigen oordeel in fase 1.** Bij gemengde groep: *"Karim, schrijf JOUW eerste indruk eerst even op. Daarna vergelijken jullie."* Voorkom dat MBO-4 de MBO-3-er voorzegt.
- **Een ruwe stoplichtscore is genoeg.** Bij weigeraars (*"ik heb een precies getal nodig"*): *"In de echte productie heb je nooit perfecte info — een eerste filter volstaat."*

## Valkuilen

- **Verlamde deelnemer (5 min met pen in hand).** Geef richting via concrete tel-opdracht: *"Tel even kolom 3 — hoeveel cellen zijn leeg?"* Concrete actie haalt de drempel weg.
- **Trainer geeft te snel het antwoord weg.** Per cel zeggen *"die is leeg, rode vlag"* maakt de sessie frontaal en doelgroep haakt af. Pas in fase 3 maak je het framework expliciet.
- **Verbeterplan wordt klacht of wenslijst voor de teamleider.** Maak het feitelijk: welke vraag, welke eigen actie deze week?

## Voorbereiding (25 min vooraf)

- [ ] Werkbladen wb-01 t/m wb-04 printen (n + 2 reserve per stuk)
- [ ] Voorbeelddataset spuitgieten (A4, 25 rijen, n + 5 reserve)
- [ ] Flap-over voorgemarkeerd: VOLLEDIGHEID | CONSISTENTIE | ACTUALITEIT
- [ ] Markeerstiften groen/oranje/rood — 1 set per duo
- [ ] Stickers per cel kolom (rood/oranje/groen) — 5 per deelnemer
- [ ] Slidev geopend op laptop, beamer getest
- [ ] Drie vuistregels paraat (tellen wat leeg is / kijken of het klopt / kijken hoe oud)

## Transferopdracht

*"Kies deze week een dataset van je eigen werkvloer. Voer de drie checks uit (volledigheid, consistentie, actualiteit). Geef per check een stoplichtoordeel (groen / oranje / rood) en onderbouw met één concrete observatie. Werkblad 4 mee naar de volgende sessie."* Vooruitblik: *"Lo-data-lit-302 (audit op je hele afdeling) bouwt hier op voort."*
