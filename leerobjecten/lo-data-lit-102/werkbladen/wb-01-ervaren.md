> **Over dit werkblad**
> In de fabriek worden vier soorten data verzameld: getallen, tekst, beelden en signalen. In deze oefening ga je zelf op zoek. Je kijkt welke data jij tegenkomt bij je eigen machine of werkplek.

---

## 1. Welke data zie jij?

*Kijk om je heen op je werkplek. Vul per soort data een voorbeeld in dat jij herkent.*

| Soort data | Wat is het? | Jouw voorbeeld |
|------------|-------------|----------------|
| **Getallen** | Meten en tellen: temperatuur, druk, aantallen | |
| **Tekst** | Logboeken, overdrachten, storingsbeschrijvingen | |
| **Beelden** | Foto's, camera's, scans | |
| **Signalen** | Trillingen, geluiden, temperatuurverloop | |

---
