# TIS — traditioneel

- **Bereik:** één technologie, één sector
- **Doel:** marktintroductie
- **Snelheid:** stabiel (jaren)
- **Sturing:** top-down, vaak één eigenaar

::right::

# DIS — modern

- **Bereik:** meerdere technologieën, meerdere sectoren
- **Doel:** innovatie + duurzaamheid + werkprocesverandering
- **Snelheid:** snelle evolutie (kwartalen)
- **Sturing:** verdeeld, geen single point of control

<div class="text-sm opacity-75 mt-6">
Praktische consequentie: een DIS plan je niet — je navigeert hem.
</div>

# Fase 3 — Mijn DIS-canvas

<div class="text-2xl mt-6 mb-6">
Eén lopend digitaliseringsproject van **jouw afdeling**
</div>

# Verdiepingsvragen aan buurman

1. **Waarom** is die actor in dit veld?

2. **Wie ontbreekt** waarschijnlijk?

3. Welk veld is **dunner dan ik zou verwachten**?

::right::

# Plenaire patroonvraag

> *"Welk veld bleek bij de meeste teamleiders dunner dan verwacht?"*

Verwachte blinde vlekken:

- Vakbonden + medezeggenschap
- Regelgeving (vooral EU AI Act 2026)

<div class="text-sm opacity-60 mt-4">
Maakt voor het hele project uit — niet alleen voor compliance.
</div>
