# Twin Transition — wat is het?

**Digitalisering** alleen levert *efficiency-winst*.

**Duurzaamheid** alleen levert *transformatie*, maar mist de motor.

**Twin Transition** koppelt beide: digitale tools sturen actief richting decarbonisatie.

::right::

# Vier kwadranten

| | Greener — | Greener + |
|---|---|---|
| **Smarter +** | ⚠️ Spanning | ✅ Synergie |
| **Smarter —** | 🟫 Stilstand | 🟢 Greener-only |

# Fase 3 — Casus

## AI-energie-optimalisatie in de procesindustrie

Een Nederlands procesindustriebedrijf installeert een AI-systeem dat parameters real-time aanpast om energieverbruik te verlagen. Investering: €1,8M. Verwachte ROI: 18 maanden.

**In drietallen — 20 minuten:**

1. Welk kwadrant: smarter, greener, of synergie?
2. Wat zou je toevoegen om het naar synergie te trekken?
3. Welke onbedoelde effecten zou je kunnen monitoren?

<div class="text-sm opacity-60 mt-6">
Geen goed antwoord — verschillende drietallen kunnen verschillende kanten kiezen.
Trainer faciliteert plenair de patroonherkenning.
</div>

# Sturen vs glijden

| Glijden | Sturen |
|---------|--------|
| "Wij doen aan digitalisering" | "Wij doen smarter + greener" |
| Alleen techniek meten | Ook duurzaamheid meten |
| ROI op kosten | ROI op CO₂ + kosten |
| Eigenaar = IT | Eigenaar = lijn + sustainability |

<div class="text-lg italic opacity-75 mt-6">
Het verschil tussen glijden en sturen is taal — wie kwadranten benoemt, verschuift gedrag.
</div>
