## 3. Reken je OEE uit

*Vermenigvuldig de drie percentages met een rekenmachine of telefoon.*

| Stap | Rekening | Uitkomst |
|------|----------|----------|
| Beschikbaarheid (in komma) | __________ |  |
| x Prestatie (in komma) | __________ |  |
| x Kwaliteit (in komma) | __________ |  |
| = OEE (in komma) | | __________ |
| OEE in procenten | | __________ % |

> **Tip:** 87,5% schrijf je als 0,875. Vermenigvuldig zo: 0,875 x 0,90 x 0,98 = 0,77.
