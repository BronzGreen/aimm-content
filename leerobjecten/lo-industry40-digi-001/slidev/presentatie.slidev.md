# Snelle herkenningsoefening

<div class="text-base mt-8 text-left">

**1.** Thermostaat regelt 180°C zonder operator → ❓

**2.** Scherm toont machines in groen/geel/rood → ❓

**3.** Bij elke afkeur: foto + parameters opgeslagen → ❓

**4.** Operator + onderhoud + planning op shared lijst → ❓

**5.** AI stopt pomp bij red-alarm → ❓

</div>

<div class="text-sm opacity-60 mt-6 italic">
Onderbouw je keuze — niet alleen aanvinken
</div>

# Casus — pomp 2008-2024

<div class="text-base mt-6">

**Fase 1 (2008)** — Lokale regeling: PLC + HMI + lokaal alarm

**Fase 2 (2014)** — SCADA: trends + audit-trail

**Fase 3 (2019)** — Predictive maintenance + dashboards

**Fase 4 (2024)** — Geïntegreerd platform: data → werkorder → planning

</div>

# Hypothese — waarom ontbreekt die mode?

<div class="text-base mt-8 text-left">

⬜ **Geen aandacht** — wel waarde, niet topprioriteit

⬜ **Geen capaciteit** — wel ambitie, mensen ontbreken

⬜ **Organisatorische weerstand** — werkprocessen veranderen is moeilijk

⬜ **Geen techniek beschikbaar** — leverancier biedt het niet

</div>

Welk vakje vink je aan voor jouw afdeling?
