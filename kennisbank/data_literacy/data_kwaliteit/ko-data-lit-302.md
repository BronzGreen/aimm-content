# Een datakwaliteit-audit op je eigen afdeling

Een datakwaliteit-audit is een systematische check van je eigen data. Je beoordeelt per databron de volledigheid, consistentie en actualiteit, en maakt een plan om de grootste problemen op te lossen.

In Module 2 heb je geleerd hoe je datakwaliteit beoordeelt met drie checks. Nu ga je die checks systematisch toepassen op ALLE databronnen van je eigen afdeling.

### Wat is een datakwaliteit-audit?

Een audit is een gestructureerde check. Je loopt al je databronnen langs en beoordeelt ze op dezelfde criteria. Het resultaat is een overzicht: welke data is goed, welke data heeft aandacht nodig?

### Stap 1: Inventariseer je databronnen

Maak een lijst van alle plekken waar data wordt vastgelegd op je afdeling:
- MES-systeem (productiedata, OEE, storingen)
- Logboek (handmatige notities)
- Excel-bestanden (weekrapportages)
- Kwaliteitssysteem (meetwaarden, afkeuringen)
- Planbord of planning-tool (orders, planning)

### Stap 2: Beoordeel per bron

Geef per databron een score op de drie criteria:

| Databron | Volledigheid | Consistentie | Actualiteit | Totaal |
|----------|-------------|-------------|-------------|--------|
| MES-systeem | ++ | ++ | ++ | Goed |
| Logboek | + | - | + | Matig |
| Excel-rapport | + | + | - | Matig |
| Kwaliteitssysteem | ++ | + | ++ | Goed |

### Stap 3: Identificeer de grootste risico's

Focus op data die je gebruikt voor beslissingen (hoge impact), data die structureel onvolledig is (niet incidenteel), en data waar meerdere mensen van afhankelijk zijn.

### Stap 4: Maak een verbeterplan

Per probleem: wat is het probleem, wat is de oorzaak, wat is de oplossing, wie pakt het op, wanneer klaar?

### De audit als terugkerend ritueel

Plan een kwartaalcheck. Zijn de verbeteringen doorgevoerd? Zijn er nieuwe databronnen? Is de kwaliteit verbeterd?


## Praktijkvoorbeeld

Een operator voert een audit uit op de lakstraat. Grootste risico: kleurcode-registratie met drie verschillende schrijfwijzen ("RAL3020" vs "rood" vs "3020"). Oplossing: dropdown-menu in plaats van vrije tekst. Resultaat: consistente data, betrouwbare kleurrapportages.
