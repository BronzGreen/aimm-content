# Wat is OEE? Hoe goed draait jouw machine echt?

**OEE** staat voor Overall Equipment Effectiveness. In het Nederlands: de algehele effectiviteit van je apparatuur. Het is een getal dat drie vragen beantwoordt:

1. **Draait de machine?** (beschikbaarheid)
2. **Draait de machine snel genoeg?** (prestatie)
3. **Maakt de machine goede producten?** (kwaliteit)

### De formule

**OEE = Beschikbaarheid x Prestatie x Kwaliteit**

Elk onderdeel is een percentage. Door ze te vermenigvuldigen krijg je het totaal.

### Wat betekent het getal?

| OEE | Betekenis |
|---|---|
| 100% | Perfecte productie: geen stilstand, maximale snelheid, nul afkeur |
| 85% | World class -- dit is het doel voor de meeste fabrieken |
| 60% | Typisch voor veel bedrijven -- er is ruimte voor verbetering |
| 40% | Er gaat veel productietijd verloren -- actie nodig |

### Waarom is OEE nuttig?

OEE geeft je een **eerlijk beeld** van hoe je machine presteert. Zonder OEE denk je misschien dat je machine 90% van de tijd draait. Maar als je de snelheidsverliezen en afkeur meetelt, is het echte getal vaak veel lager.

OEE helpt ook bij het stellen van **prioriteiten**: waar verlies je de meeste productietijd? Bij stilstand? Bij snelheidsverlies? Bij kwaliteitsproblemen? Het antwoord bepaalt waar je verbeteractie het meeste oplevert.

**Belangrijk:** OEE is een hulpmiddel om te verbeteren, niet om af te rekenen. Het gaat niet om het getal, maar om de **trend** en de **verliezen** die je ermee zichtbaar maakt.

## Praktijkvoorbeeld

Een verpakkingslijn draait 8 uur per dag. De machine staat 45 minuten stil door een storing en 15 minuten voor omstellen. Als hij draait, haalt hij 90% van de maximale snelheid. Van de geproduceerde verpakkingen is 98% goed. De OEE is: (7/8) x 0.90 x 0.98 = 0.875 x 0.90 x 0.98 = 77%. Dat klinkt redelijk, maar er is nog 23% verbetering mogelijk.
